# OpenAPI Viewer Module

`babelforge.openapi-viewer` is an installable BabelChrome viewer module for OpenAPI and Swagger documents.

It renders local and remote YAML, YML, and JSON sources through Symfony, Swagger UI, Twig templates, AssetMapper assets, and `babelforge/babel-chrome-viewer-kit`.
